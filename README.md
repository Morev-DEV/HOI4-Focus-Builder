# HOI4 Focus Maker

Tired of writing the same commands over and over again while creating national focus trees in Hearts of Iron IV?

So was I. That's why I decided to make a small Python utility to simplify the process of creating and editing focus trees.

I originally made this tool for personal use, but I thought it might be useful to other HOI4 modders as well. So here it is!

## Features

**1. Automatic File Creation and Editing**

Creates or edits national focus files directly in your specified mod directory.

**2. Automatic Script Generation**

Automatically generates the basic structure of focus trees and individual focuses, saving you from writing repetitive code.

**3. Customizable Focuses**

When creating a focus, the utility asks you to specify:

- Prerequisites and dependencies
- Completion rewards and effects
- National spirits (ideas)
- Focus positioning within the tree
